# 🕐 Astute Desk Clock

A Nothing OS-inspired, pixel-perfect landscape desk clock for Android, built with Kotlin & Jetpack Compose.

## ✨ Features
- Stadium boundary tick dial (adaptive to 16:9 → 21:9 aspect ratios)
- Punch-hole cutout aware edge-to-edge rendering
- Immersive fullscreen with transient swipe bars
- Sensor landscape rotation (180° flip for charging stands)
- Battery-efficient: redraws only once per second
- Pure #000000 OLED-friendly background
- FLAG_KEEP_SCREEN_ON desk mode

## 🛠 Tech Stack
Kotlin · Jetpack Compose · Material 3 · Min SDK 26 · Target SDK 35
